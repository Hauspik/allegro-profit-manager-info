# Allegro Profit Manager

Allegro Profit Manager jest wewnętrzną aplikacją firmy Hauspik służącą do analizy rentowności sprzedaży na Allegro.

Aplikacja wykorzystuje Allegro REST API do odczytu danych dotyczących ofert, zamówień i operacji billingowych.

## Główne funkcje

- analiza rentowności ofert i zamówień,
- analiza kosztów i opłat Allegro,
- analiza marży po kosztach sprzedaży,
- rekomendacje zmian cen,
- analiza produktów i zestawów,
- analiza efektywności działań reklamowych,
- optymalizacja sprzedaży przy zachowaniu docelowej rentowności firmy.

Aplikacja jest wykorzystywana wyłącznie na potrzeby własnych kont sprzedażowych Hauspik.
